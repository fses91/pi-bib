# Contributing

Thanks for considering a contribution to `pi-bib`.

Before opening an issue or pull request:

- Keep reports and proposals short and specific.
- For bugs, include minimal reproduction steps and any error messages.
- For feature proposals, describe the problem before suggesting a solution.
- Do not include private bibliography data, unpublished manuscripts, API keys, or other sensitive information.

For code changes, please run these before submitting:

```bash
npm run check
npm run typecheck
```
